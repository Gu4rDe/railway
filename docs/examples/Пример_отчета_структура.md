# Пример отчёта: структура

Источник: [`../../archive/source-documents/examples/Пример отчета (1).pdf`](../../archive/source-documents/examples/Пример%20отчета%20%281%29.pdf).

Это пример курсовой работы по дисциплине «Методы разработки программных
систем». Предметная область исходного примера — библиотека; документ полезен
как образец состава UML-документации и руководства пользователя, но не является
описанием текущей железнодорожной системы.

## Основные разделы

1. **Задание по курсовой работе**
   - требования к проекту;
   - распределение задач;
   - перечень UML-диаграмм;
   - требования к хранению данных и составу документации.
2. **Диаграммы UML**
   - варианты использования;
   - классы;
   - деятельности;
   - состояний;
   - компонентов;
   - развёртывания;
   - последовательности.
3. **Руководство пользователя со скриншотами**
   - введение и область применения;
   - назначение и условия применения;
   - подготовка к работе;
   - операции администратора;
   - операции библиотекаря;
   - операции читателя.
4. **Приложение А**
   - исходные тексты программы.
5. **Использованные источники**.

## Требования из примера

Документация к курсовой работе должна включать задание, UML-диаграммы,
описание классов и методов, руководство пользователя со скриншотами, набор
тестов и результатов отладки, а также тексты программ с комментариями.

Пример показывает, как связывать диаграммы вариантов использования с ролями
пользователей и как строить отдельные сценарии последовательности для операций
системы. Для текущего проекта названия ролей и предметную область следует брать
из железнодорожной модели, а не копировать библиотечные сущности.
