# Архитектура системы «Железная дорога»

Архитектурный каркас будущего кода находится в `railway/`:

- `railway/backend/` — Python web backend;
- `railway/frontend/` — TypeScript/React frontend.

## Доменные контексты

| Контекст | Ответственность | Основные объекты |
| --- | --- | --- |
| Identity | учётные записи, роли и вход | `User`, `Administrator`, `Operator` |
| Infrastructure | управление станциями, операторами и поездами | `Station`, `Train` |
| Routing | проверка прямых направлений и поиск подходящих поездов | доступные прямые направления поездов |
| Cargo | отправка, приём, перевозка, выдача и отслеживание грузов | `Cargo`, `CargoStatus` |

`Train` хранит начальную и конечную станции прямого направления, а `Cargo`
ссылается на отправителя, получателя и станции отправления и назначения. Груз
может быть назначен на поезд. Эти связи проходят через контракты модулей, а не
через прямой импорт внутренних моделей.

Учётные записи пользователей создаёт администратор. Оператор регистрирует
прибытие поезда на конечную станцию, выгружает назначенные грузы, а получатель
подтверждает выдачу.

## Слои backend

- **Domain** — бизнес-правила и инварианты.
- **Application** — сценарии использования и порты.
- **Infrastructure** — БД и внешние реализации портов.
- **Presentation** — HTTP API и преобразование входных/выходных данных.
