# Cargo module

Жизненный цикл груза: отправка, ожидание приёма, приём на станции, назначение
на поезд, движение, доступность к выдаче и подтверждение получения. Оператор
станции получает рабочий список только своей станции и может фильтровать его
по статусу; отправитель и получатель отслеживают связанный с ними груз по
идентификатору, а получить его может только назначенный получатель.
