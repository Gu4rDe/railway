# Railway application

Будущий программный продукт для информационной системы «Железная дорога».

## Приложения

- [`backend/`](backend/README.md) — Python web-сервис, доменная логика и API.
- [`frontend/`](frontend/README.md) — web-клиент на TypeScript и React.

Исходные UML-диаграммы и проектная документация остаются на верхнем уровне
репозитория в `uml/` и `docs/`. Каталог `railway/` предназначен только для
исполняемого кода и его контрактов.
