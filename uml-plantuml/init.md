# Инициализация работы с PlantUML

Перед созданием или изменением UML-диаграммы:

1. Определи тип диаграммы и одну идею, которую она должна показать.
2. Прочитай соответствующий шаблон в [`references/templates.md`](references/templates.md).
3. Сверь предметную область с исходниками текущего проекта в `uml/` и
   материалами в `docs/`.
4. Собери `.puml` с базовыми настройками раскладки из
   [`SKILL.md`](SKILL.md).
5. Сохрани исходник и сгенерированные `.png`/`.svg` вместе в тематической
   папке `uml/`.
6. Отрендери изменённый файл через `scripts/render-plantuml.sh` и проверь
   результат визуально.

Для текущего проекта используются две основные папки:

- `uml/class-diagram/` — классы железнодорожной системы;
- `uml/use-case-diagram/` — варианты использования и роли пользователей.

Не создавай диаграмму с большим количеством несвязанных элементов. Если модель
перестаёт читаться на одном листе, раздели её на несколько диаграмм по типам,
ролям или подсистемам.
